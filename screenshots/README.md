# Evidence images (MIVACARE HOSPITAL)

These images are **captures of real script output**, generated by `render_evidence.py` from the
outputs of the scripts in this repository. They come from **SQLite 3.45.1**, not MySQL Workbench,
and each image is captioned that way. Re-run `python3 render_evidence.py` to regenerate them.

| Image | Shows |
|---|---|
| p1-schema-and-data.png | Tables, keys and foreign keys created; sample data loaded |
| p2-query-results.png | Results of queries 1-6 |
| p2-explain-before-index.png | Execution plans before indexing (full scans) |
| p2-explain-after-index.png | Execution plans after indexing (index searches) |
| p2-performance-summary.png | Before/after timing table |
| p3-commit-rollback.png | COMMIT and ROLLBACK |
| p3-atomicity-savepoint.png | CHECK failure rolled back; SAVEPOINT |
| p3-concurrency.png | Locking and prevented duplicate payment |

No MongoDB, replication or cloud screenshots are included, because those were not run.
Add your own MySQL Workbench screenshots here if you have them.
